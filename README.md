# Explainable-AI-Disaster-Severity

AI-powered real-time disaster severity prediction, explainable risk analysis, and dynamic emergency resource allocation.

## Overview
This project provides an explainable AI framework for predicting disaster severity in real-time, helping emergency response teams prioritize resources efficiently with transparent and interpretable AI insights.

## Pilot Project
**Real-Time Urban Flood Emergency Management for Hyderabad / Telangana**

## Project Structure
- `backend/` - FastAPI REST services & endpoints
- `dashboard/` - Real-time command-centre interactive frontend
- `data/` - Datasets and preprocessing scripts
- `ml/` - Severity prediction models & training pipelines
- `tensorflow_models/` - Time-series LSTM deep learning architectures
- `xai/` - Explainable AI modules (SHAP, LIME, Feature attribution)
- `optimization/` - Google OR-Tools multi-resource allocation engine
- `rag/` - Government guideline retrieval & Disaster Copilot
- `gis/` - GeoPandas & spatial risk-zone mapping
